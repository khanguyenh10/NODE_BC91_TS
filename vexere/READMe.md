# Vexere

## Kiến thức có được
- token
- authentication
- validation
- apis
- refactor code

## init project
1- khởi tạo project: `yarn init`
2- cài các thư viện cần thiết `yarn add express mysql2 sequelize`
3- cài các thư viện cần thiết cho môi trường dev `yarn add sequelize-cli --dev`
4- khởi tạo project với `sequelize init`
